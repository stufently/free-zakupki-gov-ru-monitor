# Changelog

## 0.2.0 — 2026-07-25

### Исправления

- **Критическое исправление:** парсер RSS переписан с `DOMParser` на строковый (regex-based) парсинг. `DOMParser` недоступен в service worker Chrome MV3, что приводило к ошибке `ReferenceError: DOMParser is not defined` при проверке лент. Новый парсер работает без DOM API, поддерживает RSS 2.0, Atom, namespaced теги (`dc:date`), CDATA и декодирование HTML entities (включая двойное кодирование)
- **Дедупликация записей:** `pushRecent` теперь дедуплицирует записи по `link` (или `feedId:title`), предотвращая появление дублей в popup при повторных проверках

### Улучшения

- **Группировка лент в popup:** записи сгруппированы по лентам с заголовками и счётчиками. Группы свёрнуты по умолчанию, клик по заголовку разворачивает/сворачивает список
- **Кнопки сброса лент:** добавлены кнопки «Сбросить» для каждой ленты (в настройках) и «Сбросить все ленты» (глобальная). Очищают `initialized` и `seenIds`, позволяя увидеть последние записи из ленты заново без переустановки расширения
- **Первый запуск ленты:** при первой проверке ленты последние 10 записей добавляются в popup (без уведомлений), чтобы пользователь сразу видел содержимое ленты

## 0.1.0 — 2026-05-01

Первый публичный релиз.

- Chrome MV3 расширение для мониторинга RSS-лент zakupki.gov.ru
- Service worker с `chrome.alarms` для периодической проверки
- Настройки: список лент (CRUD), кастомный интервал в минутах (1 минута – 7 дней, по умолчанию 10 минут) + presets
- Уведомления через `chrome.notifications`, клик открывает страницу закупки
- Badge text с количеством непрочитанных записей
- Popup со списком последних найденных записей
- Локальное хранилище (`chrome.storage.local`), без внешних запросов кроме fetch RSS
- Парсер RSS 2.0 и Atom без зависимостей, namespace-aware (поддержка dc:date)
- inFlight guard на concurrent проверки + троттлинг 1.5 сек между фидами
- Дедупликация лент по canonical URL
- Явный флаг `initialized` для корректного first-run при пустых фидах
- GitHub Actions: автоматическая сборка ZIP и публикация в Releases по тегу `v*`
- Fixture-тесты на парсер (14 assertions)
