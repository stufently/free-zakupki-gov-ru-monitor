# Политика конфиденциальности

**Расширение:** Бесплатный мониторинг госзакупок (zakupki.gov.ru)
**Дата вступления в силу:** 29 июля 2026 года
**Разработчик:** [stufently](https://github.com/stufently), исходный код открыт под лицензией MIT

## Назначение

Единственное назначение расширения — следить за RSS-лентами государственного
портала закупок zakupki.gov.ru и уведомлять пользователя о новых записях в них.

## Коротко

Расширение не собирает персональные данные, не передаёт их третьим лицам и не
отправляет никуда статистику. У него нет серверной части: всё, что оно делает,
происходит внутри вашего браузера.

## Какие данные обрабатываются

Все перечисленные данные создаёте вы сами, и хранятся они локально в
`chrome.storage.local` — на вашем компьютере, в профиле браузера:

| Данные | Зачем |
|---|---|
| Ссылки на RSS-ленты и их названия | Собственно то, за чем следит расширение |
| Настройки расписания и лимитов | Интервал проверки, размер списка, лимит уведомлений |
| Идентификаторы уже показанных записей | Чтобы не уведомлять дважды об одной закупке |
| Список последних найденных записей | Показывается в popup |
| Диагностика по каждой ленте | Время последней проверки, число записей, текст ошибки |

Расширение не читает содержимое страниц, которые вы открываете, не имеет доступа
к истории просмотров, вкладкам, буферу обмена, файлам и учётным записям.

## Куда уходят сетевые запросы

Единственный сетевой запрос — загрузка RSS-ленты по адресу, который вы добавили
сами. В коде это один-единственный вызов `fetch` в
[`extension/background.js`](../extension/background.js), и разрешения
расширения ограничены доменом портала:

```json
"host_permissions": ["https://zakupki.gov.ru/*", "https://*.zakupki.gov.ru/*"]
```

Обратиться к другому сайту расширение технически не может — браузер не позволит.

Запрос анонимный: он выполняется с явным `credentials: "omit"`, поэтому ваши
cookie портала не отправляются, даже если вы залогинены на zakupki.gov.ru.
Разрешения `cookies` у расширения нет, авторизацию оно не использует и не
запрашивает. Портал видит обычное обращение к своей открытой RSS-ленте.

## Передача данных третьим лицам

Не осуществляется. В расширении нет аналитики, счётчиков, телеметрии, рекламных
и партнёрских библиотек, нет загрузки удалённого кода. Данные не продаются, не
передаются и не используются для оценки кредитоспособности.

## Разрешения и зачем они нужны

| Разрешение | Назначение |
|---|---|
| `alarms` | Периодическая проверка лент по вашему расписанию |
| `notifications` | Показ уведомления о новой закупке — основная функция |
| `storage` | Локальное хранение перечисленного выше |
| `offscreen` | Разбор XML: в Manifest V3 service worker не имеет доступа к DOM API. Offscreen-документ ничего не отображает и не делает сетевых запросов |
| `host_permissions` | Загрузка лент с zakupki.gov.ru |

## Как удалить данные

Удалите расширение через `chrome://extensions` — вместе с ним браузер удалит и
всё его хранилище. Очистить выборочно можно там же: «Подробности» → «Просмотр
данных хранилища». Кнопка «Очистить» в popup стирает список найденных записей.

## Дети

Расширение адресовано специалистам по закупкам, данные детей не собираются и
целенаправленно не обрабатываются.

## Как проверить написанное

Не верьте на слово — исходный код открыт:

- сетевые запросы: `grep -rn "fetch(" extension/` — вызов ровно один, с `credentials: "omit"`;
- хранилище: [`extension/storage.js`](../extension/storage.js);
- разрешения: [`extension/manifest.json`](../extension/manifest.json).
